# Simple Game Prototypes

This repository contains basic game prototypes developed to explore game logic, algorithmic thinking, and modern development workflows.

## Projects

### 1. Slither (Snake Game)
A classic arcade experience built with **HTML5 Canvas** and **JavaScript**.
- **Core Mechanics:** Dynamic game loop management and collision detection.
- **Level Design:** Score-based difficulty scaling, speed adjustments, and obstacle placement across multiple levels.
- **Features:** Responsive controls and a custom UI for settings and score tracking.

### 2. Word Guess (Hangman Style)
An interactive word-guessing game focused on UI/UX and event handling.
- **Data Management:** Features a large dataset across 10 distinct categories (Movies, Technology, Sports, etc.).
- **Dynamic Visuals:** SVG-based character feedback system (Boy, Girl, Animal, Robot) that reacts to user guesses.
- **Interface:** Built with JavaScript and CSS3, focusing on a responsive and user-friendly experience.

## Development Process & Tools
These projects were developed using **Cursor AI** to experiment with AI-assisted software engineering. 
- **Planning:** Utilized "Plan Mode" to architect the project structure and logic flows.
- **Optimization:** Reviewed and manually optimized AI-generated code to ensure engineering best practices and efficient performance.

## How to Play
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. (For Slither) Use Arrow keys or WASD to navigate.
